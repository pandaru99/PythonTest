# Grok + VSCode + Python 환경 설정 가이드

## 1. VSCode에서 Grok 연결 방법

### 추천 확장 프로그램
- **Simply Grok for VSCode** — 가장 간단
- **Grok AI / xAI for VS Code** (GMDevCore) — 채팅 + 인라인 완성
- **Cline** — 강력한 AI 코딩 에이전트

### 설치 및 설정 단계
1. [console.x.ai](https://console.x.ai/)에서 **API Key** 발급
2. VSCode Extensions에서 원하는 확장 설치
3. `Ctrl + Shift + P` → **"Grok: Set API Key"** 검색 → 키 입력
4. 단축키
   - 채팅 열기: `Ctrl + Shift + G`
   - 코드 설명: `Ctrl + Shift + E`

### 4. 네이버 증권 외국인·기관 거래내역 가져오기 2
```python 방법 2: pandas.read_html
import pandas as pd
import requests

def get_investor_trading(ticker):
    url = f"https://finance.naver.com/item/frgn.naver?code={ticker}"
    headers = {"User-Agent": "Mozilla/5.0"}
    df_list = pd.read_html(requests.get(url, headers=headers).text)
    df = df_list[2]   # 테이블 번호는 확인 필요
    print(df.head())
    return df
```
